### 1. Make the run folder (from the register row, nothing by hand)
cd $FR && KIT kit_new SCOUT SCO-A<n> $RUN --type ALARM_BUILD --version V26
It writes library/ and root/ of the run. Refused words (VERSION_NOT_CURRENT, NOT_REGISTERED, MANIFEST_SHA, PACK_CHECK) mean stop.

### 2. The launcher builds the agent prompt from the pack
The orchestrating session runs a Workflow script; copy FR/team/SCOUT/pack_kit/launchers/ALARM_RUN_LAUNCHER_EXAMPLE_TRIALJ.js and change the brief name, its sha16, the version and labels. Four agents in order:
prep (fills PROMPT_V26 into the run's prompt and ops/PARENT_STEP.md, answers one JSON line), launcher (checks sha16s, runs init), hunter (follows the prompt to the end), parent close.
The init, the launcher's last command before the hunter:
cd $FR && KIT init SCOUT SCO-A<n> $RUN --type ALARM_BUILD --version V26 --brief $RUN/<RUN BRIEF>.md
It writes ops/RUN_PROMPT.md, ops/RUN_ENV.sh (TL, B, KIT, LOOP, SEATWIN, PYD) and opens the time log at the phase start.
