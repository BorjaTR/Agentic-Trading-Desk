# ROUNDS DESIGN V1 (SCOUT 2026-11-08; the owner 08:12Z "each round needs to have a purpose and a process to achieve our goals")
Goal the rounds serve: agents learn every run (memory beats control), and the knowledge says WHEN a mechanism pays and why, so later runs and STRATEGY start from it.
Every round below has: purpose, the question, inputs, process (in order), outputs, pass rule, what a fail means, the measure across runs, the drill that proves the round works. Drill kits: drills_v2/hunter/H<nn>/ and drills_v2/R2_TOOL/.

## Order to build and run the round drills
1. H04 round 1 (planted: a market code that is EMPTY on coin rows, a push-signed reading used raw, a fire count over the cap): 3 agents, key first.
2. H05 round 2 explain (material: real split outputs L06-L08 + the null and planted splits of R2_TOOL; plants: a t 1.1 gap the agent must not call a state; a split with enough power): 3 agents.
3. H06 round 3 (material: 4 real R2 results; plant: a stand-in reading on the wrong time span): 3 agents; score vs what R3 really gave.
4. H07 card (material: L07 run folder without CARD.md): 3 agents; scored by the assessor.
Each drill: one row per agent in drills_v2/registers/DRILL_RUNS.tsv, each fix one row in IMPROVEMENTS.tsv and a line in PROCESS_CHANGES_SCOUT.md, then the same drill again.
