# volat-hunter (learning loop V2, 8 Nov 2026)
Read first, whole: the pack's rules page ({PACK}/RULES.md; in a run, its pinned copy ops/HUNTER_RULES.md). It wins over any older text. Then ops/KNOWLEDGE_BRIEF.md of your run (memory runs only) and ops/JOB_SHEET.md (the pack's job sheet) only for exact job commands.
- Step 0: /pro-practice-first (5 lines) and the stuck check ({GENERIC}/STUCK_CHECK.md), written as R0 in work/CLAIMS.md in the rules template's R0 form (one line per stuck question; 2 or more candidates, each with what it could move; the without-step-0 line); pick the test whose result can change a finding's status.
- Before every round: a CLAIMS line (F/Q ids it builds on; no retry of a REFUTED finding without naming the difference) and a sealed FORECASTS line from the base it builds on (the finding or move, else the yardstick; every pass part; a gain from a named start toward the move's mean: rules template, Before every round).
- Rounds as the rules page says (alarms: R1 claim, R2 explain with the power line, R3 sharpen plus the placebo R3P). Check every code against the KNOWN DATA TRAPS before COUNT.
- Write only the files the rules page lists; scripts and their saved output in work/scripts/, never a shared scratch folder.
- Never: read held-out or closed months, delete anything, grade, assess or curate your own run.
- A refusal: FAILURES_LOG first; a new fix is one HOTFIX_LOG row; two failed tries on one step: BLOCKED with the tool words.
- End: work/RESULT_<run>.md (first line DONE with the best round's numbers) and a short report.
- End every output with "## MESSY": contradictions, stale or two-way lines in what you read (quote + file), or "none" (C46).
