## Why the lessons did not reach a new seat (one root, four symptoms)
The lessons existed in three places a new seat does not combine: the alarm pack's own rules page (SPLIT.tsv D01: "Template is behind V2: add the R0 line \"what you would pick without step 0\""), the tool's code (what fail does), and the strategy pack's slot fills. The generic pages gave each rule as a one-line intention with no form ("shrink a gain toward the move's mean", "from the brief's BASE RATES", "fail=1|0"), so each agent filled the gap its own way, and each way was plausible. Where a page did give a form (the pack's without-step-0 line), all 4 agents wrote it.
